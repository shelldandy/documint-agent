# Specifications Directory

This directory contains all project specification documents organized chronologically and by category.

## Naming Convention

**Format:** `{sequence}-{category}-{document-type}.md`

- **Sequence:** Two-digit number (00-99) for chronological ordering
- **Category:** Primary focus area (exec, prd, technical, api, etc.)
- **Document-type:** Always ends with descriptive suffix (summary, prd, specification, requirements, etc.)

## Benefits

1. **Chronological Order:** Files sort naturally by creation/priority sequence
2. **Clear Categorization:** Each filename immediately identifies the document's purpose
3. **Machine Readable:** Consistent kebab-case formatting for automation
4. **Human Readable:** Descriptive names that don't require opening the file
5. **Scalable:** Easy to insert new documents between existing ones (00a, 00b, etc.)
