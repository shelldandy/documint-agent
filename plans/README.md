# Plans Directory

This directory contains all project planning documents organized chronologically and by category.

## Naming Convention

**Format:** `{sequence}-{category}-{document-type}.md`

- **Sequence:** Two-digit number (01-99) for chronological ordering
- **Category:** Primary focus area (mvp, technical, api, database, etc.)
- **Document-type:** Always ends with descriptive suffix (roadmap, design, plan, strategy, specification)

## Benefits

1. **Chronological Order:** Files sort naturally by creation/priority sequence
2. **Clear Categorization:** Each filename immediately identifies the document's purpose
3. **Machine Readable:** Consistent kebab-case formatting for automation
4. **Human Readable:** Descriptive names that don't require opening the file
5. **Scalable:** Easy to insert new documents between existing ones (01a, 01b, etc.)
